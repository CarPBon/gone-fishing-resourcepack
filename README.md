# gone-fishing-resourcepack
The Gone Fishing! mod breaks textures when only installed server-side. This is to remedy that.
## How to use
Click on the resource pack version in the repo that you want, copy the Raw link, and add it to your `resource-pack` field in server.properties.
Optionally add the SHA-1 of the chosen resource pack to the `resource-pack-sha1`:
| Resource pack | SHA-1 |
| :---: | :---: |
| go-fish-26.3.zip | c11dbe24ad4d2a60241d740d2e29ff5afdaec192 |
